A simple clock based on Arduino Nano. 
It features clock, date, timer, alarm, and thermometer functions. It is equipped with 4 push-buttons and 4 toggle switches. 
Toggle switches: Pin A0 (night mode), A1 (switch units from Celsius to Fahrenheit), A2 (alarm enable), A3 (lock display to temperature or seconds). 
Push-buttons: D4 (MODE_MENU), D5 (UP), D6 (DOWN), D7 (SELECT). 
ST7735S 80x160 display: D13 (SCL), D11 (SDA), D12 (RES), D9 (DC), D10 (CS). 
RTC (DS3231): A4 (SDA), A5 (SCL). TM1637: D2 (CLK), D3 (DIO). 
Speaker (via D304X transistor): D8 (connected via a 470Ω–1kΩ resistor).
